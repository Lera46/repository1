# Джунгоу цхай — сайт азиатской кухни

Лендинг для доставки азиатской еды, созданный в лабораторной работе №4
и доработанный в ЛР №5 с использованием Git и ИИ-агента.

## Технологии
- HTML5
- CSS3 (адаптивная вёрстка)
- JavaScript (фильтры меню, корзина-уведомления, форма обратной связи)
- Google Fonts (DM Sans, Playfair Display)

## Ветви проекта
- `main` — стабильная версия
- `feature-assets` — замена и добавление фотографий
- `feature-docs` — документация и текстовые материалы
